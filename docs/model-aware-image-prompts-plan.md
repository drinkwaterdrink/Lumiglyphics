# Model-aware image prompts

Implement the approved model-aware image pipeline on Testing. Preserve existing templates,
styles, references, appearance evidence, held requests and manual parameter controls.

1. Resolve a frozen prompt profile from the exact provider/model, verified public metadata,
   documented family guidance, conservative unknown-limit fallback, and optional manual budget.
2. Share that profile between planning, semantic repair, review, regeneration and final validation.
   A manual budget is a combined character ceiling; known provider ceilings still apply.
3. Detect the requested families without assuming that similarly named routes have identical
   limits. Cache public NanoGPT discovery with a short timeout and bundled verified fallback.
4. Give writers model-specific guidance. Preserve evidenced identity/action/layout/lettering;
   deduplicate negatives before rewriting, never blindly truncate. Unsupported negatives must
   be translated into positive visual intent or held for repair.
5. Add automatic profiles and manual budget controls in Images, explain the resolved profile
   in the reader, and label blocked drafts. Keep old records on the legacy 3000 ceiling.
6. Verify small/large limits, overrides, unknown metadata, review persistence, raw overrides,
   rerolls, cancellation, external review and final dispatch. Run full validation and browser QA.

Metadata describes compatibility, not a guaranteed artistic optimum. No paid automatic model
comparisons or speculative sampler overrides. Model-native token budgets require an actual
tokenizer before claiming exact token counts; show the character fallback honestly.
