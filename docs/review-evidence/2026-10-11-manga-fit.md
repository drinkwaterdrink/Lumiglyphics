# Testing beta.5 — portrait Manga pages

Manga now defaults to tall portrait output: OpenRouter's host adapter uses `aspectRatio: "9:16"`; NanoGPT uses `size: "864x1536"`. The per-template Output shape control can retain connection defaults. Older saved Manga entries gain this default only when the shape field is absent; existing wording is preserved. Explicit extension parameters and raw request overrides remain authoritative. Unsupported adapters retain their connection parameters. Selected model acceptance is provider-dependent and has not been tested with paid requests.

Complete pages use contain fitting with a dim, blurred copy behind them, reserve space above the text, and bypass the readability scrim and image zoom crop. The page inspection icon temporarily hides reading controls and pauses automatic advancement. Ordinary images restore the selected fit. Cached pages retain their durable cue presentation; manual re-preparation uses the latest approved request metadata.

Validation: 1252 unit tests across 100 files, plus 18 speech transport tests; strict typecheck; production build; bundle checks; mobile-reader and image-template browser scripts. Bun 1.3.14 remains below the declared 1.4.0 engine requirement; existing Node browser adapter and transport keepalive were used. Screenshots inspected at `.cache/mobile-reader/manga-page.png`. No live Lumiverse installation, physical-device check or paid provider call was run.

A read-only reviewer found cache-hit and oldest-request metadata problems; both were fixed and cache-hit behavior has a regression test. The reviewer then stopped at an account usage limit, so a completed independent review is not claimed.

Roadmap: package B and the requested Manga/mobile feedback are delivered. Explicit card-role/correction controls in A and packages C–G remain pending. This release does not introduce the tooltip/entity provider foundation yet.
